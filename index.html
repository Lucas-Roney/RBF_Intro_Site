RBF Learning Hub Guide

Welcome to the Radial Basis Function Learning Hub! Explore RBF function interpolation and apply RBF techniques to real-world data using the following modules:

  • RBF Playground: An interactive sandbox to test how different radial basis functions (Gaussian, Multiquadric, Inverse MQ, Inverse Quadratic) approximate 1D curves and 2D surfaces as you adjust node counts and the shape parameter ε. Polynomial interpolation is also included, so you can directly compare RBF Interpolation to Polynomial.

  • Tidal Data Interpolation: A practical tool for reconstructing downsampled tidal data from different coastal NOAA datasets (Wilmington, Rhode Island, and real LIVE data) through both RBF and polynomial interpolation. Interactively cut to simulate missing or lost data to then attempt interpolating the gap.
