RBF Playground Guide

Explore radial basis function interpolation interactively using the sidebar controls:


  • 1D / 2D Toggle: Switch between 1D curve interpolation and 2D surface interpolation.

  • Function: Choose the target function to interpolate (Runge, sin(3x), |x|, or Polynomial).

  • Kernel: Select the RBF (Gaussian, Multiquadric, Inverse MQ, Inverse Quadratic, or even Polynomial).

  • Shape Parameter (ε): Adjust the shape parameter to see how it affects the interpolant in different situations.

  • Number of Nodes: Adjust the count of evenly spaced data points given from the test function.

  • Best ε Button: Automatically computes and applies the optimal shape parameter for the lowest error.
